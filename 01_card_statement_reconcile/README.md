# カード明細の照合・按分・振替CSV作成ツール（サンプル）

ガソリンカードの月次利用明細を題材に、PDFの読み取りから台帳照合、按分、会計用CSVの作成までを自動化するサンプルです。データはすべて架空で、実案件の成果物ではありません。

## 処理の流れ

1. 利用明細PDFから、明細行と請求合計を読み取ります。
2. カード管理台帳と照合し、対象月に有効な施設と利用者を特定します。
3. 按分対象のカードは、按分表の割合で施設に配分します。
4. 施設別の振替CSV、集計表、エラー一覧を出力します。

## 正確さのための設計

- **推測で処理しません。** 判断できないデータはエラー一覧に出し、振替から除外します。
- **按分後の合計は元の金額と必ず一致します。** 端数は最大剰余法で配分します。
- **PDFの請求合計と検算します。** 読み漏れがあれば `TOTAL_MISMATCH` になります。
- **未確定のCSVを取り違えません。** エラーが1件でもあると、ファイル名が `振替_2026-10_要確認.csv` になります。エラーが解消すると `振替_2026-10.csv` だけが残ります。
- **カード番号の全桁を出力しません。** 出力は下4桁だけです。
- **台帳の変更に対応します。** 有効開始日と終了日から、対象月に有効な行を使います。

## 検出するエラー

台帳にないカード、対象月に無効なカード、台帳の重複、施設や利用者の未入力、施設マスタにないコード、按分先の不足、割合の合計が100でない按分、金額の読取不可、対象月外の利用日、明細Noの重複、解釈できない行、請求合計の不一致。

## 使い方

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python generate_dummy_data.py
.venv\Scripts\python reconcile.py --month 2026-10 --input data/input --output output
```

エラーをわざと含む `data/input` では、10件のエラーが出ます。修正後の状態を示す `data/input_fixed` を指定すると、エラーは0件になり、振替額が請求合計の 1,021,620円と一致します。

原本を確認して直す金額や利用日は、`corrections.csv` に書いて再実行します。

```text
明細No,金額,利用日,理由
17,4200,,原本で金額を確認
```

終了コードは、確定が 0、要確認が 1、入力ファイルの問題で中止が 2 です。

## テスト

```bash
.venv\Scripts\python -m pytest -q
```

## 実案件で調整する点

- 実際のPDFの形式に合わせた読み取り処理。スキャン画像のPDFにはOCRが別途必要です
- 既存の会計システムのCSV形式と勘定科目
- 既存の端数処理ルール
- 個人情報を扱うファイルの保存場所とアクセス権限

実行時に生成AIは使わないため、明細データは外部のAIサービスに送られません。開発には生成AI（Claude）を使い、テストで動作を確認しました。
