# スプレッドシートの請求作成・入金確認の自動化（サンプル）

Google スプレッドシートと Google Apps Script（GAS）で、月次請求の作成と入金確認を自動化するサンプルです。データはすべて架空で、実案件の成果物ではありません。

## できること

- 受注一覧から、顧客ごとの月次請求を作成します。
- 消費税は、請求書ごと・税率（10%、8%）ごとに合計してから切り捨てます。
- 支払期限を、月末からの支払日数で計算します。
- 入金一覧と照合し、未入金、一部入金、入金済み、過入金を判定します。
- 期限を過ぎた請求について、督促文の下書きを作ります。メールは送信しません。

## 例外の扱い

次のデータは推測で処理せず、「確認リスト」に出します。

- 顧客マスタにない顧客、重複した受注ID
- 数量、単価、税率、日付の入力ミス
- 請求と結び付かない入金、金額が正しくない入金

問題のある受注がある顧客は、不完全な請求を出さないよう、修正されるまでその月の請求全体を保留します。

## 使い方

1. 新しいスプレッドシートを開き、「拡張機能」から Apps Script を開きます。
2. `src/Logic.js` と `src/Main.js` の内容を貼り付けて保存します。
3. スプレッドシートを開き直し、メニュー「請求自動化」の「サンプルデータを入れる」を実行します。
4. 続けて「請求と入金状況を作成」を実行します。

「請求一覧」「入金状況」「確認リスト」のシートが作られます。何度実行しても、同じ入力なら同じ結果になります。

## 構成

| ファイル | 役割 |
|---|---|
| `src/Logic.js` | 金額計算と判定。Google のサービスに依存しません |
| `src/Main.js` | シートの読み書きとメニュー |
| `tests/logic.test.js` | 自動テスト |

## テスト

```bash
node --test tests/logic.test.js
```

計算処理に加えて、簡易モックを使ってシートの読み書きの流れも確認しています。実際の Google スプレッドシート上での実行確認は、このテストには含まれません。

## 実案件で調整する点

- 締め日と支払条件、端数処理のルール
- 請求書PDFの作成、会計ソフトへの連携
- 督促メールを送る場合の承認の手順
- 顧客情報を扱うスプレッドシートの共有範囲

実行時に生成AIは使っていません。金額の計算は、同じ入力で必ず同じ結果になるようルールで処理しています。開発には生成AI（Claude）を使い、テストで動作を確認しました。
